# دستیار هوشمند کسب‌وکارهای مجازی

Multi-tenant SaaS برای وارد کردن محصولات از Excel/Google Sheets، ساخت مدل داخلی پایدار، رندر پست با Preset + AI اختیاری، انتشار و همگام‌سازی در پلتفرم‌های پیام‌رسانی (Telegram، Bale، Eitaa، Rubika) و مدیریت از طریق پنل‌های Web/Telegram/Bale.

## وضعیت فعلی

- **Phase 0 — Approval & baseline**: در انتظار تأیید مالک برای `FINAL_APPROVAL_GATES_V1` (Gates A–H)
- طبق قرارداد Bootstrap (`00_START_HERE.md`)، پیاده‌سازی پایه **شروع نشده** است

## مستندات

- `docs/PROJECT_UNDERSTANDING_REPORT_V1.md` — گزارش فهم پروژه (اولین خروجی AI Developer)
- `docs/specification/` — پکیج کامل طراحی (۲۲ سند) — در انتظار انتقال نهایی به ریپو
- سند ورود اجباری: `00_START_HERE.md` (در پکیج اسناد)
